# سامانه اخبار

![پیش‌نمایش سامانه اخبار](cover.png)

وب‌سایت خبری PHP برای جمع‌آوری خودکار اخبار از منابع RSS، ذخیره در دیتابیس و نمایش با قالب فارسی.

موتور واردات فید را می‌خواند، متن کامل را استخراج می‌کند، تکرار را حذف می‌کند و همان خبر را در صفحه اصلی، دسته، منبع و سایت‌مپ نشان می‌دهد. پنل مدیریت محتوا، منابع و قالب را بدون دست‌زدن به کد عوض می‌کند.

**توسعه‌دهنده:** گروه برنامه‌نویسی کا جی اس ام  
**استک:** PHP 7.4 · MySQL / MariaDB · Smarty 3 · SimplePie · Apache

## امکانات

### سایت

- صفحه اصلی با خبر ویژه (VIP)، پربازدیدترین‌ها و آخرین اخبار
- صفحه دسته، منبع، مطلب و جستجو
- صفحات ثابت: تماس، درباره ما، شبکه‌های اجتماعی، پیوندها، منابع، تبلیغات
- اخبار مرتبط (جستجوی FULLTEXT روی عنوان؛ در صورت نبود، از همان دسته)
- شمارش بازدید هر مطلب
- تاریخ شمسی با `jdf.php`
- آدرس‌های سئو و فارسی از طریق `.htaccess`
- RSS و سایت‌مپ
- بلوک‌های تبلیغاتی از پوشه `ads`

### واردات خودکار اخبار

فایل `upnew.php` منابعی را که به‌روزرسانی خودکار دارند می‌خواند و خبرهای جدید را وارد می‌کند:

- پارس فید با SimplePie
- جلوگیری از تکرار با لینک و عنوان
- استخراج تصویر اول از متن HTML
- بررسی تطابق عنوان با محتوا
- حذف عنوان تکراری از ابتدای متن
- قوانین جایگزینی متن برای هر منبع
- قابل اجرا از کرون یا مرورگر

### پنل مدیریت (`/panel/`)

- ورود و تغییر رمز عبور
- آمار ارسال ماهانه
- مدیریت اخبار، دسته‌ها، منابع RSS، صفحات و پیوندها
- تنظیمات عمومی و قالب
- آپلود تصویر منبع
- ویرایشگر TinyMCE

## پشته فنی

| بخش | فناوری |
| --- | --- |
| زبان | PHP 7.4 |
| دیتابیس | MySQL / MariaDB (`arzpress_db`) |
| اتصال | mysqli با UTF-8 |
| قالب | Smarty 3 |
| فید | SimplePie |
| HTML | simple_html_dom |
| تقویم | jdf |
| موتور متن کامل | FiveFilters Full-Text RSS در پوشه `tech` |
| پنل | Bootstrap، Font Awesome، Morris.js |
| وب‌سرور | Apache با `mod_rewrite` |

## ساختار پروژه

```text
ponisha/
├── index.php                 صفحه اصلی
├── article.php               تک‌خبر
├── category.php              دسته
├── source.php                منبع
├── search.php                جستجو
├── page.php                  صفحات ثابت
├── rss.php                   خروجی RSS
├── sitemap.php               سایت‌مپ
├── upnew.php                 کرون جمع‌آوری اخبار
├── jdf.php                   تاریخ شمسی
├── .htaccess                 قوانین بازنویسی URL
├── include/                  هسته برنامه، کانفیگ و Smarty
├── panel/                    پنل مدیریت
├── themes/default/           قالب HTML
├── ads/                      کدهای تبلیغاتی
├── tech/                     استخراج متن کامل از صفحه خبر
├── cache/                    قالب‌های کامپایل‌شده Smarty
├── upload/                   فایل‌های آپلودشده
└── go/                       ریدایرکت و لینک
```

## جداول دیتابیس

| جدول | نقش |
| --- | --- |
| `news` | اخبار (عنوان، متن، لینک، دسته، منبع، VIP، انتشار، بازدید، زمان) |
| `categories` | دسته‌بندی‌ها |
| `sources` | منابع RSS و قوانین جایگزینی متن |
| `pages` | صفحات ثابت |
| `links` | پیوندها |
| `options` | تنظیمات سایت و قالب |

## مسیرهای مهم

| مسیر | توضیح |
| --- | --- |
| `/` | صفحه اصلی |
| `/fa/news/{id}/{slug}` | مطلب |
| `/fa/service/{id}/{slug}` | دسته |
| `/fa/query/{id}/{slug}` | منبع |
| `/page/{id}/{slug}` | صفحه ثابت |
| `/tag/{عبارت}` | جستجو |
| `/feed` | RSS کلی |
| `/rss-{id}.xml` | RSS دسته |
| `/categories-sitemap.xml` | سایت‌مپ دسته‌ها |
| `/panel/` | مدیریت |
